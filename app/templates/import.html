Structure attendue

Chaque événement doit contenir ces cinq champs.

timestamplevelservice messageevent_type
  • Date : ISO 8601 avec fuseau horaire.
  • Niveaux : DEBUG, INFO, WARNING, ERROR, CRITICAL.
  • Familles : http, application, sql ou business.
  • JSON Lines : un objet JSON par ligne, extension .json ou .jsonl.
  • Des champs supplémentaires sont requis selon la famille.

L’aperçu vérifie les dix premiers événements. Le fichier complet est contrôlé pendant l’ingestion.
